From the repo root:

```bash
cd /home/sayed/journal_paper_proj/pi_sim
source .venv/bin/activate
python attack_clients/attack_manager.py --scenario full_eval
```

Common options:

```bash
# Full evaluation, 30s per attack, benign clients running throughout
python attack_clients/attack_manager.py --scenario full_eval --duration 30 --stagger 3

# Quick test
python attack_clients/attack_manager.py --scenario sequential --duration 5 --stagger 1

# See available attacks/benign clients
python attack_clients/attack_manager.py --list
```

If you want root-only attacks too (`icmp_flood`, `syn_flood`):

```bash
sudo -E .venv/bin/python attack_clients/attack_manager.py --scenario full_eval --duration 30 --stagger 3
```
