### Stop order (do earlier steps first)

1. **Gateway**  
   ```bash
   pkill -f '/gateway/gateway\.py'
   ```  
   (Or **Ctrl+C** in the terminal where `python gateway/gateway.py` is running.)

2. **MQTT firewall**  
   ```bash
   sudo systemctl stop mqtt_firewall
   ```  
   If it was started by hand (not systemd):  
   ```bash
   pkill -f 'mqtt_firewall\.py'
   ```

3. **Mosquitto**  
   ```bash
   sudo systemctl stop mosquitto
   ```  
   Alternative: `sudo service mosquitto stop`

---

### One line (systemd firewall + same machine)

```bash
pkill -f '/gateway/gateway\.py' 2>/dev/null; sudo systemctl stop mqtt_firewall mosquitto
```

**Why this order:** gateway releases its MQTT session first; firewall stops before the broker so the inline filter/queue is not left active while Mosquitto goes away; Mosquitto last.
